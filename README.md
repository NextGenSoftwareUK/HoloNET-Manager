# HoloNET Manager

Part of the [HoloNET](https://github.com/holochain-open-dev/holochain-client-csharp) ecosystem — the .NET/C# client for Holochain.

HoloNET Manager is a WPF desktop application for managing Holochain conductors and installed hApps. It provides a GUI for connecting to conductors, installing/uninstalling hApps, calling zome functions, and monitoring agent activity.

This repo also contains the HoloNET Manager Installer (WiX-based MSI).
