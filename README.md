# HoloNET Manager

Part of the [HoloNET](https://github.com/holochain-open-dev/holochain-client-csharp) ecosystem — the world's first .NET & Unity client for Holochain.

**[https://holonet.oasisomniverse.one](https://holonet.oasisomniverse.one)**

The official desktop UI for HoloNET — a feature-complete WPF application showcasing every Client and ORM capability. Install and manage hApps, call zome functions, monitor agent activity, and explore the full Holochain Conductor API through a rich UI. Provides generic backend and UI components for rapid hApp construction. Being ported to MAUI, Uno & OpenSilver for cross-platform native deployment.

This repo also contains the HoloNET Manager Installer (WiX-based MSI).
